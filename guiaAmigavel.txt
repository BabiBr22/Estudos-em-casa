# Guia JavaScript para Iniciantes Absolutos

## 0. O que é JavaScript?
JavaScript é uma linguagem de programação que permite fazer páginas web interativas. É como dar instruções ao computador, similar a uma receita de bolo.

## 1. Primeiros Passos

### 1.1 Como Escrever e Executar Código
```javascript
// Você pode escrever JavaScript em:
// 1. Navegador (Chrome, Firefox) - Aperte F12, vá em "Console"
// 2. VS Code - Crie um arquivo com .js no final (exemplo.js)
// 3. Sites como CodePen.io

// Este é um comentário - computador ignora esta linha
console.log("Olá, mundo!"); // Isto mostra texto na tela
```

### 1.2 Variáveis - São como caixas para guardar coisas
```javascript
// Guardando informações
let nome = "João";        // Guarda texto
let idade = 25;          // Guarda números
let gostaDePizza = true; // Guarda sim/não (verdadeiro/falso)

// Mostrando as informações
console.log(nome);         // Mostra: João
console.log(idade);        // Mostra: 25
console.log(gostaDePizza); // Mostra: true

// Mudando valores
nome = "Maria";           // Podemos mudar o valor
console.log(nome);        // Agora mostra: Maria

// Exemplo prático:
let preço = 50;
let desconto = 10;
let preçoFinal = preço - desconto;
console.log(preçoFinal); // Mostra: 40
```

### 1.3 Operações Básicas
```javascript
// Matemática básica
let soma = 5 + 3;        // 8
let subtração = 10 - 4;  // 6
let multiplicação = 3 * 4; // 12
let divisão = 10 / 2;    // 5

// Juntando texto (concatenação)
let primeiroNome = "João";
let sobrenome = "Silva";
let nomeCompleto = primeiroNome + " " + sobrenome;
console.log(nomeCompleto); // Mostra: João Silva

// Forma moderna de juntar texto
let apresentação = `Meu nome é ${primeiroNome} e tenho ${idade} anos`;
console.log(apresentação); // Mostra: Meu nome é João e tenho 25 anos
```

### 1.4 Tomando Decisões (if/else)
```javascript
// Verificando condições
let idade = 15;

if (idade >= 18) {
    console.log("Você é maior de idade");
} else {
    console.log("Você é menor de idade");
}

// Exemplo prático:
let hora = 14;

if (hora < 12) {
    console.log("Bom dia!");
} else if (hora < 18) {
    console.log("Boa tarde!");
} else {
    console.log("Boa noite!");
}
```

### 1.5 Repetições (loops) - Fazendo algo várias vezes
```javascript
// Contando de 1 a 5
for (let numero = 1; numero <= 5; numero++) {
    console.log(numero);
}

// Exemplo prático: Tabuada do 2
for (let i = 1; i <= 10; i++) {
    console.log(`2 x ${i} = ${2 * i}`);
}
```

### 1.6 Listas (Arrays) - Guardando vários valores
```javascript
// Criando uma lista
let frutas = ["maçã", "banana", "laranja"];

// Mostrando itens da lista
console.log(frutas[0]); // Primeiro item: maçã
console.log(frutas[1]); // Segundo item: banana

// Adicionando item novo
frutas.push("uva");

// Mostrando cada fruta
for (let fruta of frutas) {
    console.log(`Eu gosto de ${fruta}`);
}
```

### 1.7 Funções - Criando "receitas" reutilizáveis
```javascript
// Criando uma função simples
function saudação(nome) {
    return `Olá, ${nome}!`;
}

// Usando a função
console.log(saudação("João")); // Mostra: Olá, João!

// Função prática: Calculadora
function somar(a, b) {
    return a + b;
}

let resultado = somar(5, 3);
console.log(resultado); // Mostra: 8
```
